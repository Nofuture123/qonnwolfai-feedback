# 穹狼AI 问题反馈

内部员工反馈穹狼AI客户端(学生端 / 员工版)问题的入口。

> 链接始终指向最新版本。

## 怎么用

1. 点上方 **Issues** → **New issue** → 选「问题反馈」
2. 按表单填写:选产品、写清复现步骤
3. 提交后机器人会自动把反馈转入开发仓,并在你的 issue 下回复跟进链接

## 注意

- 描述越具体(复现步骤、截图、报错原文),修复越快
- 一个问题一条 issue,不要打包多个问题
